# Lista de Tarefas com Tema Dinamico

Projeto academico feito com React, JavaScript e styled-components.

## Funcionalidades

- Adicionar tarefas
- Marcar tarefa como concluida
- Remover tarefas
- Filtrar por todas, ativas e concluidas
- Alternar entre tema claro e escuro

## Tecnologias

- React
- JavaScript
- styled-components
- Vite

## Como rodar

```bash
npm install
npm run dev
```
