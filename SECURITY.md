# Politica de Seguranca

## Escopo

Este repositorio e uma aplicacao de portfolio para gerenciamento de tarefas. Mesmo sem backend proprio, problemas de seguranca em dependencias, build, GitHub Pages ou manipulacao de dados locais devem ser tratados.

## Como reportar

Nao abra issue publica com segredo, token, exploit reproduzivel ou dado sensivel. Use um contato privado indicado no perfil do GitHub ou abra um aviso privado de seguranca quando o recurso estiver disponivel.

Inclua:

- versao, commit ou URL afetada;
- passos de reproducao;
- impacto esperado;
- evidencia minima sem expor dados de terceiros.

## Compromisso

Relatorios validos devem ser triados antes de qualquer publicacao publica do detalhe tecnico. Se houver credencial exposta, a primeira acao e rotacionar ou revogar antes de discutir a correcao.
