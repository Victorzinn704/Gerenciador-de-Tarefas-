# Como Contribuir

Este projeto funciona como demonstracao publica de frontend React. Mudancas devem manter o repositorio simples de executar, testar e revisar.

## Fluxo recomendado

1. Abra uma issue ou PR pequeno com escopo claro.
2. Explique o problema resolvido e o comportamento esperado.
3. Rode os checks locais antes de pedir revisao.

## Checks locais

```bash
npm ci
npm run lint
npm run test
npm run build
```

## Padrao de PR

- mantenha o diff focado;
- atualize README ou docs quando alterar comportamento visivel;
- adicione ou ajuste testes quando corrigir regra de interface;
- nao publique credenciais, dados pessoais ou arquivos locais.
